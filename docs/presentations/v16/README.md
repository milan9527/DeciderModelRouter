## P5 · 五步原始支付流程

同一 USDC 待确认任务，每个节点每模型一次；应用后端毫秒，包含排队与提供方调用。GPT 为 **GPT-6.1 Sol low**。

| 决策步骤 | Decider | Jev | GPT |
|---|---:|---:|---:|
| 客服受理 | 78.7 | 491.4 | 922.8 |
| 支付核验 | 83.7 | 368.4 | 992.6 |
| 风控审批 | 109.9 | 488.9 | 2074.8 |
| 资金处理 | 81.5 | 361.4 | 2167.4 |
| 客户回复 | 76.1 | 469.8 | 3333.0 |
| 五步合计 | 429.8 | 2179.8 | 9490.6 |
| 与演示参考一致 | 4/5 | 4/5 | 5/5 |

Decider 和 Jev 在本例额外选择了等待人工审批；GPT 避免了该阻塞。三者仍需等待链上确认从 3/12 达标，均未入账或结案。参考一致次数不等于通用准确率，决策耗时之和也不是业务完成耗时。

适用场景总结：Decider 用于经过领域验收的高频分类、工具选择和分流；Jev 用于证据核验和多步操作，另组浏览器验证完成 10/10（Decider 4/10）；GPT 用于复杂条件和开放式任务，回复、代码等质量仍需单独验收。不同验证集不混合计算分数。

## P19 · 最新原始客服路由

请求：“回复客户的问题：USDC 已转出，为什么订单仍显示待支付？当前链上确认数为 3/12。”

| 路由器 | 选择流程均值 | 选择型号均值 | 两步合计 | 所选型号 |
|---|---:|---:|---:|---|
| Decider | 96.0 ms | 353.2 ms | 449.2 ms | Claude Opus 5 |
| Jev | 492.1 ms | 425.7 ms | 917.8 ms | Claude Opus 5.5 |
| GPT-6 Sol low | 1297.8 ms | 1176.3 ms | 2474.1 ms | GPT-6 Luna |

三路都选择 `customer_support`。两步分别由对应模型判断，同阶段输入与候选相同，每步三轮取均值；未使用增强输入或程序代选。这一页只比较路由，不评价目标生成或业务完成情况。

**补充结论与已知问题：** [失败原因与多模态改进分析](failure-analysis.zh.md)完整列出21、10、11项未通过的原因分组。Liquid和H2O均有7项涉及媒体内容、格式或能力未接通；Decider另有13项通用路由或输出模态问题。中文语音、文生图、文生视频3项的文字验收与边界标记不一致，当前仍被计入失败，尚未修复，不能直接解释成决策模型判断错误。

## 规则

整体验收通过率 =（完整答案验收通过 + 预设边界正确拦截）/ 全部计划场景。

- **通过**：完整输出的现有有效评分通过；或者零费用、空模型允许列表、缺少图片等用例预先要求拒绝且正确拦截。3次边界通过单列，未混入答案正确率。
- **未通过**：非预期无路由/执行受阻、边界违约、调用错误、输出未完成、完整答案不合格。最新批次非预期无路由/执行受阻为15、5、5项；完整答案不合格为6、5、6项，合计21、10、11项。
- **待评**：输出完整但尚无质量判定。三种模型均为英语向量、中文向量和语音生成3项。
- **未测**：预登记能力/评测数据缺口、预算未执行、尚无记录或尚不可判定。当前三种模型均为16项预登记缺口。

四类互斥且总和等于87。运行中和中断后的尚无记录也留在原计划分母；零已记录结果不会显示100%或无分母。待评和未测没有被判错，但不能增加已证实通过比例。已判定覆盖率 =（通过 + 未通过）/ 全部计划场景，本批均为68/87（78.2%）。

原“44/50、55/60、54/60”保留为“已评分答案通过（辅助）”，只反映有答案/调用评分的子集，不能拿来替代整体排名。任务类型标签匹配作为诊断项，最终答案满足验收要求就可通过，不因内部标签不同而否决有效结果。路由性能、目标延迟和参考费用仍独立展示。

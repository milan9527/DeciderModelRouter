已在现有 GPU 上启用第二阶段编译加速；第一阶段保留原推理路径。每次路由仍为两次 GPU 调用，各一次前向计算，依据和全部合格候选保持不变。

来自同机轮换的46组固定路由输入，不含ECS网络、建池及目标生成。随后正式HTTP服务、三个模型常驻时，第二阶段P50/P95为784/866ms。启动预热约109秒，新形状使用同一GPU的eager推理。

**一致性边界**：正式92份输入的368个字段一致、46次选模一致；加上额外产线预热输入，已知选模一致性为46/47（97.9%）。额外用例从Opus5.5改选MiniMaxM2.1，4096-token预算下两次真实目标输出都截断，均失败。不是任意输入一致性保证。

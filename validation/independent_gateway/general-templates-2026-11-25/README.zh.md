# 简单通用模板恢复

工作台恢复8个原有简单模板，显示在行业模板前；共29个模板，可按类别或关键词筛选。模板填入问题、验收参考和输出预算，用户仍可自由编辑，路由过程不依赖模板类别。

| 类别 | 恢复的模板 | 期望 / 最大输出 Token |
| --- | --- | --- |
| 通用对话 | 英文问候、中文问候、日常知识、自由写作、澄清需求、生活建议 | 256 / 1024 |
| 文本 | 中英翻译、会议摘要 | 512 / 1024 |

恢复原模板的ID、问题、验收参考和预算，不向工作台加入分类参考答案。现有21个行业、检索和多模态模板逐字段保留；12行业Agent场景及四轮任务保持不变。默认决策模型仍为Liquid。

[数据核验](data-verification.json)记录模板版本、恢复列表及未变动文件摘要。分类参考集仍为35条模板、24条带标签用例；历史87场景效果报告没有变更。

[软件验证](software.json)：79项现有网关、效果评测和行业Agent回归测试通过。[线上浏览器检查](browser.json)覆盖29个模板的任务、验收参考、预算、输出类型填充，以及分类筛选、关键词搜索、桌面与手机布局、12个行业Agent入口。[部署核验](aws-verification.json)记录ECS、CloudFront和Runtime状态。此次没有新增模型推理，也没有产生新的模型效果分数。

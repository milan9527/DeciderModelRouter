## 实测结果

主批次每次目标输出上限为 **2048 tokens**：213 次 GPU 分类、166 次独立目标调用，覆盖 12 个实际 Bedrock 型号；共保存 531 行结果，其中 283 行复用相同用例、相同有效请求的目标观察。相同观察不是独立重复样本。16 个预登记能力或评测数据缺口不调用模型，也不冒充已测。

| 决策模型 | 任务类型判断正确 / 已查 | 任务通过 / 已判定 | 已评分占全部用例 | GPU 往返 P50 / P95 |
|---|---:|---:|---:|---:|
| Decider | 49/71 | 40/50 | 57.5% | 344.1 / 383.6 ms |
| Liquid d1 | 70/71 | 50/60 | 69.0% | 96.6 / 99.7 ms |
| H2O Lightning | 70/71 | 49/60 | 69.0% | 545.9 / 551.3 ms |

**任务通过比例是已判定样本上的条件指标，不能当作全部场景准确率。** 任务类型判断正确只判断用途是否匹配，不代表模型选择最优。开放答案使用助手辅助评审，代码使用隔离功能测试；未引入独立人类金标。每种路由方案仍有 3 项待评：中英文向量的检索质量、英文语音的听感质量。

166 个目标观察中，146 个具有用量和参考价格，已知部分合计 **$2.201986**；未含未知媒体价格及 GPU、ECS、存储、网络费用，不是 AWS 账单。顺序运行的延迟不能推导并发吞吐。

## 关键发现及证据

1. **分类参考一致率低不等于所有回答错误。** 主批次 Liquid 和 H2O 的任务类型判断正确均为 70/71，但仍会把普通 JSON 输出误判为提供商强制 Schema，导致无候选。Decider 会把纯文字问候或翻译分到语音等工作流；`hi` 返回了不需要的音频。内容正确与输出模态相容需要分别评分。
2. **部分失败来自推理 token 预算。** 主批次的行程规划、并发设计等耗尽 2048 token，没有最终答复。另做了[8192-token 补测](budget-followup/README.zh.md)：2 次 GPU、6 次目标调用，5 个完整答案经内容评审通过，低价模型的并发设计仍截断。任务、分类、模型和推理配置逐项一致，但没有固定随机种子或重复采样；补测不并入主分数。
3. **媒体接口成功不代表语义正确。** 红色图片被回答为 “Blue.”；视频回答未说明红色花苞绽放；[去背景结果](image-edit-comparison.png)把主体柱形也变透明。蓝图回答 “Blue.” 语义正确，原精确字符串检查因大小写和句号误判，已追加可追溯评审。图表正确识别 B 但违反“只返回字母”的格式要求；ASR 的严格失败是将 `gateway` 转成 `gate way`，不能泛称完全听不懂。
4. **代码需要执行验证。** 对 8 个不同的完整函数输出执行隔离功能测试，7 个通过。唯一失败包含题目禁止的 Markdown 围栏，原样作为 Python 执行时语法错误，不能据此说算法错误。测试数、源码哈希、镜像与执行结果保存在 [code-results.json](code-results.json)。
5. **质量相同仍存在费用优化空间。** 在本次可评分、通过且价格可比的路由与对照中，Decider、Liquid、H2O 分别有 3/28、4/45、15/44 个用例存在更便宜的已测通过方案。对照只来自当前池的低价/高能力策略，不是穷举 124 型号，不能得出全局最优或统一节省比例。

本批结果支持优先评估：普通 JSON 与强制 Schema 的区分、文字与语音边界、按任务联合选择推理强度与 token 上限、媒体质量证据、以及在质量门槛下的费用选择。此次发布增加评测及证据，没有依据可见题库直接修改分类提示或训练路由器。
